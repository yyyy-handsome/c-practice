# C 语言练习项目

大一开始的 C 语言练习代码，每写一个小程序就提交一次。

## 目录结构

- hello.c —— 第一个程序
- build/ —— 编译产物（不提交到 Git）

## 怎么编译运行

bash 命令（MSYS2 终端里执行）：

    cd /d/Dev/Code/c-practice
    gcc hello.c -o build/hello.exe
    ./build/hello.exe
